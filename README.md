# Site de Wooosh

Site vitrine de Wooosh (Motion Blur en temps réel pour Windows).
Site statique : `index.html`, `style.css` et le dossier `images/`. Rien à installer ni à compiler.

- Voir le site : double-cliquer sur `index.html`.
- Couleurs et polices : les mêmes que l'application (design system « Pose longue »).
- Captures d'écran : copiées depuis le dossier du logiciel (`ui_dark_0.png`, `ui_light_0.png`).
